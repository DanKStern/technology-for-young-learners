# Systems, Hierarchy & Nesting — Band C (Grades 3–5, ages 8–10)

**Core idea:** a computer file has an address made of folders inside folders (a path), and living things are sorted into a formal hierarchy too (kingdom down to species, simplified).

**Spiral note:** builds on [[Systems, Hierarchy & Nesting - B Grades 1-2]] — folders-in-folders was physical and informal; this band makes it formal with a real file-explorer path, and pairs it with the biological classification hierarchy as a second real-world example of the same nesting pattern, echoing [[Life & Living Systems - C Grades 3-5]]'s cells idea.

## Hands-on activities
- Open a real file explorer and navigate `Documents → Pictures → Vacation → photo.jpg`, writing out the full path.
- Build a simplified classification tree for a few familiar animals (e.g., animal → mammal → dog → golden retriever).
- Compare a nested-boxes picture next to the file path next to the animal classification — same shape, three domains.
- Organize a shared drawer or shelf at home with a labeled folder-like structure and navigate it out loud.

## Vocabulary

Words this band uses, defined the way we'd describe them to someone who'd never seen them — what happens, not how it feels:

- **Path** — the full list of nested locations needed to find one specific thing, written in order from widest to narrowest.
- **Classification** — a formal system that sorts living things into nested groups, agreed on and used the same way by everyone.
- **Level** — one step in a nested path or classification, narrower than the one above it and wider than the one below.

Held back for later: *hierarchy* — the general name for this nested-narrowing pattern, used the same way whether it's describing files, animals, or code — arrives by name in [[Systems, Hierarchy & Nesting - D Grades 6-8]].

## Draft

### Finding the Path

Open a real file explorer and navigate down several levels into a real folder structure on the family computer, having the child write out the full path as you go, address-style: each folder name separated by a slash. Ask: "if I just told you 'photo.jpg' with nothing else, could you find it?" (No — you need the whole path, every folder in order, the same way a street address needs more than just a house number.)

### Animal, Mammal, Dog, Golden Retriever

Build a simplified classification tree for a few animals the child knows well — start broad (animal) and narrow down one level at a time (mammal → dog → golden retriever), asking at each step: "what else fits in this same box before we go one level narrower?" This is the same twenty-questions narrowing shape from Band B, just made formal and written down as a real tree instead of a guessing game.

### Same Shape, Three Places

Lay the file path and the animal classification tree side by side and ask directly: "what's the same about these two?" Both are an address made of nested boxes, each one narrower than the last, and both only make sense read in order. If a drawer, closet, or shelf at home has its own folder-like structure, organize or re-organize it together and narrate the path out loud the same way — "this is in the top drawer, in the small bin, in the left corner" — to show the pattern isn't just a computer thing.
