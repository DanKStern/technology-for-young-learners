# Computing & Logic — Band C (Grades 3–5, ages 8–10)

**Core idea:** a named, repeatable set of steps is an algorithm, loops let you repeat steps without rewriting them, and a computer (or a busy parent) can seem to do many things "at once" by switching between them quickly.

**Spiral note:** builds on [[Computing & Logic - B Grades 1-2]] — if/then rules and turn-taking are already familiar; this band names "algorithm" and "loop" directly and introduces multitasking as the fast-turn-taking idea, in step with [[Information & Communication - C Grades 3-5]]'s context-switching lesson.

## Hands-on activities
- Write out a real algorithm (steps to tie a shoe, steps to make toast) and have someone else follow it exactly, debugging where it's ambiguous.
- Use a loop explicitly: "do 10 jumping jacks" instead of writing "jump" ten times — same instruction, repeated.
- Watch a parent or older sibling "multitask" (stirring a pot while talking on the phone) and discuss whether they're really doing both at once or switching fast.
- Simple block-coding exercise (Scratch or similar) using a loop and an if/then block together.

## Draft

### Writing a Real Algorithm

Have the child write out the exact steps to do something they know well — tying a shoe, making toast — then hand the steps to someone else to follow with no help and no assumptions filled in. Watch where it breaks: a missing step, an ambiguous instruction, an order that doesn't actually work. Debug it together and try again. This is the Band B "scrambled instructions" lesson's grown-up sibling — now the child is building and fixing a real algorithm, not just reordering one. A recipe is a familiar real-world algorithm too — see [[Information & Communication - C Grades 3-5]]'s Markdown recipe lesson, where numbering the steps is the same sequencing idea written down as markup instead of just followed.

### Ten Jumping Jacks, One Instruction

Compare writing "jump" ten separate times versus writing "do 10 jumping jacks" once, and ask: "which one would you rather write if it were 1,000 jumping jacks instead of 10?" Name the second version a loop — the same instruction, repeated, without having to write it out every time. If there's a block-coding tool available, build a tiny project using an actual loop block together with an if/then block, and have the child explain in their own words what each block is doing.

### Is That Really Multitasking?

Watch someone genuinely multitasking — stirring a pot while talking on the phone, say — and ask: "is that really two things at once, or is it switching back and forth really fast?" Watch closely together for the tells: a pause in stirring during a tricky sentence, a beat of silence on the phone during a tricky stir. This is the same question [[Information & Communication - C Grades 3-5]] is asking from the message side — both strands are circling the same discovery, that "at once" is often really "fast switching" underneath.
